개인정보 처리방침 (Privacy Policy)

시행일: 2026년 11월 18일

"상상하면 과학 제작실"(이하 이 도구)은 유튜브 채널 상상하면 과학의 주인이 자기 채널에 영상을 올리기 위해 쓰는 개인용 도구입니다.

1. 사용하는 정보

이 도구는 Google 계정으로 허락받은 YouTube 권한(영상 업로드, 내 채널 영상 관리)만 씁니다. 이름, 이메일, 연락처 같은 개인정보를 따로 모으지 않습니다.

2. 정보를 쓰는 방법

허락받은 권한은 채널 주인이 승인한 영상을 그 채널에 올리고 공개 시간을 정하는 데만 씁니다. 광고, 판매, 분석에 쓰지 않습니다.

3. 보관과 공유

허락 정보(접근 토큰)는 채널 주인의 컴퓨터 안에만 저장되고, 다른 사람이나 서버로 보내지 않습니다. 제3자와 공유하지 않습니다.

4. 허락 취소

언제든 Google 계정 → 보안 → 타사 앱 액세스에서 이 도구의 권한을 취소할 수 있습니다.

5. Google API 정책

이 도구가 Google API에서 받은 정보를 쓰는 방식은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.

6. 문의

유튜브 채널 상상하면 과학의 정보 탭으로 문의해 주세요.
